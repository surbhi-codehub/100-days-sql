## 🌼 Today's Topic
**Mini SQL Project – Build and Query a Sales Database**

**Goal:** Apply everything you've learned by designing a small database, inserting sample data, and writing queries to answer business questions.

---

## 💖 A Little Message for Today

You've covered a huge portion of SQL. Today is about bringing those skills together. Instead of learning a new command, you'll use multiple SQL concepts to solve practical problems, just like you would in a real project.

---

## 📚 Quick Revision

A typical SQL project includes:

- Creating tables
- Applying constraints
- Inserting data
- Writing `SELECT` queries
- Using `JOIN`, `GROUP BY`, `ORDER BY`, and aggregate functions
- Analysing business data

---

# 🎯 Today's SQL Missions

### Mission 1 (Very Easy)
Create the following tables:
- `customers`
- `products`
- `orders`

Use appropriate `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, and `CHECK` constraints.

### Mission 2 (Easy)
Insert at least 10 sample records into each table.

### Mission 3 (Easy+)
Write queries to:
- Display all customers.
- Display all products.
- Display all orders with customer and product information using `JOIN`.

### Mission 4 (Medium)
Create reports showing:
- Total orders placed by each customer.
- Total quantity sold for each product.
- Top 5 customers based on total quantity ordered.

### Mission 5 (Challenge)
Build a business dashboard using SQL queries that answers:
- Which product sold the most?
- Which customer placed the most orders?
- What is the total quantity ordered?
- Which products have low stock?
- Which customers have never placed an order?

## 🏆 Bonus Challenge

Export your database schema and SQL queries into separate `.sql` files. Create a README describing the database, its tables, relationships, and the purpose of each query.
