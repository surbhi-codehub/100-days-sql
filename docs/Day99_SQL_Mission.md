# 🎯 Today's SQL Missions

### Mission 1 (Warm-up)
Write queries to:
- Display all employees.
- Display employees with salary greater than 60000.
- Sort employees by salary in descending order.

### Mission 2 (Filtering & Aggregation)
Using the employees table:
- Count employees in each department.
- Find the highest and lowest salary.
- Calculate the average salary by department.

### Mission 3 (Joins)
Using the existing tables:
- Display customer names with their orders.
- Display product names with total quantities sold.
- Show employees along with their department names.

### Mission 4 (Constraints Review)
Write `CREATE TABLE` statements that include:
- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- NOT NULL
- CHECK

Explain in one sentence why each constraint is useful.

### Mission 5 (Final Challenge)
Design a small business database with at least four related tables. Populate it with sample data and write five meaningful business queries using joins and aggregate functions.
